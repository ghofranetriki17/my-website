# Ghofrane Triki Portfolio

Modern one-page portfolio for GitHub Pages.

## What is inside

- `index.html` - static portfolio page, no build step required
- `assets/ghofrane-triki-profile.jpeg` - profile hero image
- `assets/Ghofrane_Triki_CV.pdf` - downloadable CV
- `.github/workflows/deploy-pages.yml` - GitHub Pages deployment workflow

## Deploy

This repository is configured for GitHub Pages with GitHub Actions.

After pushing to `main`, open:

`Settings` > `Pages`

Then set the source to **GitHub Actions** if GitHub asks for it.

The workflow will publish the static site from the repository root.

## Edit

Update `index.html` directly. The site is plain HTML/CSS and does not require Node, Vite, React, or any build command.
